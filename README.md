# Alarm Clock using Python

This is a simple alarm clock project built using Python and Pygame.  
The program takes time input from the user, starts a countdown timer, and plays an alarm sound when the timer ends.

## Features
- Countdown timer in minutes and seconds
- Real-time terminal countdown display
- Alarm sound using Pygame
- Simple and beginner-friendly project

## Technologies Used
- Python
- Pygame

## How It Works
The user enters the time in minutes and seconds.  
The program converts the input into total seconds and starts a countdown.  
Once the timer reaches zero, the alarm sound starts playing.

## Concepts Used
While building this project, I learned:
- Functions in Python
- Loops and conditionals
- Time handling using the `time` module
- Audio playback using `pygame.mixer`
- User input handling
- Basic terminal screen updating
